## 📊 Sentiment Classification Logic

### Proses Analisis
1. **Input**: User memasukkan teks
2. **Preprocessing**: 
   - Cleaning (hapus special chars, URLs, mentions)
   - Case folding (to lowercase)
   - Normalisasi slang words
   - Tokenisasi
   - Remove stopwords
   - Stemming
3. **Scoring**: 
   - Cek setiap kata di lexicon
   - +1.0 untuk kata positif
   - -1.0 untuk kata negatif
4. **Classification**:
   - Positif jika score > 0
   - Negatif jika score < 0
   - Netral jika score = 0
5. **Output**: 
   - Sentimen label
   - Confidence percentage
   - Kata-kata yang ditemukan
